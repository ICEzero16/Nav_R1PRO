# R1PRO 只读网页可视化

网页运行在机器人本机 `127.0.0.1:8088`，不向局域网直接暴露。无需安装前端依赖或联网加载资源。

机器人上运行：

```bash
cd /home/nvidia/ict_src/r1pro_navigation_ws
bash scripts/start_web.sh
```

脚本默认只启动网页，不启动雷达或点云处理。只有明确需要同时启动传感器时才传入 `--with-sensors`；该选项会复用已有适配器，否则创建独立 `r1pro_nav_sensors` 会话。当前服务已按要求停止。
网页位于 `r1pro_nav_web` 会话中，不启动 Nav2、不发布运动或制动指令。

Windows PowerShell 新开窗口运行并保持：

```powershell
ssh -N -L 8088:127.0.0.1:8088 R1PRO
```

浏览器打开 `http://127.0.0.1:8088`。如本地 8088 占用，将转发命令前一个 8088 改为 8089，浏览器也打开 8089。

## 视图

- 三维点云：每帧抽样最多 2400 点，颜色表示高度。拖动旋转，滚轮缩放，可切换俯视。
- 二维扫描：显示实际 `/r1pro_nav/scan` 回波，不把无回波方向当作已确认安全区域。
- 底盘轨迹：仅显示 odom 中的相对位置；与传感器局部坐标分开，不叠加成地图。
- 暂停画面：仅冻结浏览器显示，采集和机器人现有程序继续运行。
- IMU：原始数字，单位未确认；页面不显示虚构的航向或地图。
- 连接中断或数据过期：保留最后一帧并显示过期提示，不插值模拟实时数据。

点云/扫描在可取得对应时间 TF 时变换到 base_link，否则保留原始坐标系。
不同坐标系的点云与扫描不会叠加。已接入机器人方盒自过滤，可切换原始/过滤后点云、显示方盒和被删除点。当前代码更新尚未重新做浏览器验收。
网页最大只保留 1200 个里程计轨迹点，约最近 4 分钟，不保存传感器原始数据。

## 停止

仅停止本网页：

```bash
tmux send-keys -t r1pro_nav_web C-c
```

不再需要本页面启动的传感器会话时：

```bash
tmux send-keys -t r1pro_nav_sensors C-c
```

上述命令不结束其他本体会话。日志在 `reports/web_server.log` 和 `reports/web_sensors.log`。
